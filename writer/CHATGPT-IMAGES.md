# ChatGPT 이미지 제작 순서

이미지는 ChatGPT가 만듭니다. 사람이 사이트에서 **이미지 제작 요청 만들기**를 누르면 요청이 생기고, ChatGPT가 아래 순서로 처리합니다.

## 1. 요청 읽기
"ISHARD 작업실" 연결의 `read_production_requests`를 호출합니다(특정 콘텐츠만이면 `content_id`).
- `slots`: 장마다 `slot_id`(slide-1, scene-1, image-1 …), 확정 원고의 해당 문장 `source_text`, 기본 `prompt`, 완료 여부
- `scene`: 사람이 사이트 이미지 탭에서 장마다 적은 **장면 설명**. 비어 있지 않으면 이 장면(무엇을·어떤 구도로·어떤 소품)을 가장 먼저 따르고, `visual_rules`는 그대로 지킵니다.
- `revision_requests`: 사람이 남긴 수정 요청(`note`)과 원본 이미지(`parent_image_url`)
- `visual_rules`: 아이샤드 비주얼 규칙(반드시 지킴)
- `product_library`: 공식 제품 사실과 상세페이지 주소(제품 모양·색·라벨 확인용)
- `drive_folder`: 저장할 Google Drive 폴더

## 2. 만들기 (장마다 1장)
- 9:16 세로 독립 사진 1장. 콜라주·글씨·자막·장 번호·로고·워터마크 금지.
- 자연광, 폰으로 찍은 듯한 일상 스냅, 크림·웜그레이 바탕과 작은 올리브 연결색, 최소 소품, 정면 얼굴은 가급적 피함.
- 제품이 나오면 공식 상세페이지 사진의 **모양·색·라벨을 그대로**. 가짜 패키지 금지.
- 비누는 손이나 거품망에서 거품을 내는 장면만. 얼굴에 비누 바를 직접 문지르는 장면 금지.
- 손이 나오면 오른손·왼손 개수, 손가락 5개, 팔과 자연스럽게 이어지게.
- 전후 비교·효능 암시·가짜 후기 화면 금지.
- 수정 요청은 원본 이미지를 기준으로 `note`에 적힌 부분만 고칩니다.

## 3. 저장하고 등록하기
1. 이미지를 `drive_folder`에 `<콘텐츠ID>_<slot_id>.png`(수정본은 `<콘텐츠ID>_<slot_id>_r1.png`) 이름으로 저장합니다.
   - ChatGPT가 Drive에 직접 올릴 수 없으면, 사람에게 파일 이름을 알려주고 그 폴더에 올려 달라고 합니다. 그러면 매시간 Claude가 폴더를 확인해 자동 등록합니다.
2. Drive에 올라간 파일 링크(`https://drive.google.com/file/d/<id>/view`)로 `save_production_image(request_id, slot_id, drive_file_url)`을 호출합니다. 수정본은 수정 요청의 `request_id`로 등록합니다.
3. 등록은 후보 추가일 뿐입니다. 고르기와 **이미지 전체 확정**은 사람이 사이트에서 합니다.
